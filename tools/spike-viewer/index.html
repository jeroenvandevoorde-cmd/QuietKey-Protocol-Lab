Each cell shows the T0-selected path (verdict) then the T0-free production path: ok fail. A “Δ” marks tokens where the T0-free ok differs from its prev_ok.

2. Per family × severity (T0-selected path, tid ≠ T0)

Sums of per-token character counts from verdict_tokens.json: C = correct, e = erasure, w = silent wrong.

All tokens with ok: false in either path. Bold red = exceeds the RS(83,49) correction budget of 34.
