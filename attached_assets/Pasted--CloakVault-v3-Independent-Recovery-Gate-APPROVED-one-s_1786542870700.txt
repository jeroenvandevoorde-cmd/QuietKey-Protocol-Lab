The independent cross-language recovery milestone **passes**. This is accepted as complete:

The cryptographic and error-correction **foundation is now considered complete and independently verified**.

## The one follow-up (docs only)

The spec-gap report correctly identified a single point that required inference rather than reading: the **Forney magnitude formula**, which had to be derived from §3.2's conventions. Accept the proposed fix:

- Add the Forney error-magnitude formula to spec §3.2 as an **explicitly non-normative note** (a convenience derivation, marked as such), so a future independent implementer does not have to re-derive it. This is the only place someone had to think rather than read, and closing it strengthens the reimplement-from-scratch guarantee.

Constraints:
- **Documentation only.** Do not change any normative constant, ordering, bit convention, the code under `src/lib`, the test vector, or any behavior.
- The note is a derivation aid; it must not alter what the spec requires.
- The full validation run (94 vitest + 12 pytest + interop-cross) stays green.
- Regenerate nothing that would change the vector; the vector is frozen.
