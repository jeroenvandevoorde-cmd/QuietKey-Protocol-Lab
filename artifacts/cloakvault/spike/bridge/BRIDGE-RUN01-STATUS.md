# Bridge Run 01 — Status (additive engineering record)

Bridge Run 01 is an **invalid confirmatory session** because the pristine
start control S28 did not pass the pre-registered reader/session gate
(the reader could not reliably locate/segment its footer), while the
pristine end control S46 was read successfully.

The run remains **valuable as development data**: inspection indicates the
dominant remaining failure layer is acquisition quality, footer
localization, line segmentation, and geometric registration under curl,
perspective, folds, stains, crumpling and illumination changes — not the
frozen token codec or Reed-Solomon capacity.

All Bridge Run 01 images are **permanently considered seen
development/regression material** and MUST NOT be used as unseen
confirmation of Reader v0.2.

Formal transfer confirmation requires fresh physical pages and fresh
captures in **Bridge Run 02**.

This record is additive. It does not change any previous report, result
file, or headline number, and it does not describe the session as a
product/security failure.

Raw-capture status in this repository: Bridge Run 01 JPEGs are **not
stored here** (only the campaign log and pre-registration PDFs under
`../../bridge/`). Local replay and per-image manifests therefore could
not be generated; see `scripts/build_capture_manifest.py` for the
provenance tooling to be used when captures are available.
